# AIセルフチェックの使い方（クリエイターのみなさんへ）｜ネイルホリック

※これは初版のたたき台です。アプリの実際の操作画面ができ次第、手順を具体化します。

-----

## これは何？

レビュー依頼を出す前に、自分の制作物を専用アプリでAIにかんたんチェックしてもらう仕組みです。ねらいはシンプルで、**手戻りを減らして、みんなの制作をもっとスムーズにすること**です。

「リーダーに連絡する前に、機械的なミスを自分で見つけて直せる」状態をつくります。

ネイルホリックは商材（ネイル）が非常に多く、**使う素材・色番号・色名の取り違え**が過去に何度も起きています。しかも複製はしないルールなので、毎回イチから文字を扱う分、打ち間違いや取り違えが起きやすい案件です。このAIチェックは、まさにその「取り違え」を出稿前に自分でつぶすためのものです。

-----

## なぜやるの？（みなさんにとってのメリット）

  - レビューの往復が減って、納品までが速くなります。
  - 「言われる前に自分で直せる」ので、指摘の数が減ります。
  - 色番号・色名・素材名のうっかりミスを、リーダーに指摘される前に自分で発見できます。
  - リーダーが細かいミス探しから解放され、**デザインの中身**にしっかりFBできるようになります。結果として、もらえるフィードバックの質が上がり、スキルアップにつながります。

監視のための仕組みではありません。みなさんのアウトプットをよりよくするための「最初の相棒」だと思ってください。

-----

## 使い方（3ステップ）

1.  完成したら、アプリで**案件（ネイルホリック）を選んで、投稿画像をページ順にアップロード**します。
2.  AIチェックの結果を見て、**指摘を自分で直します**。文言・色番号・色名はCRシートから**コピペ**で反映してください。直したら、もう一度アップロードして再チェック。
3.  客観項目がOKになったら、**リーダーへ連絡（＝いつものレビュー依頼）**。このとき、AIチェックの結果も一緒に渡してください。

（具体的な操作手順は、アプリ完成後にここへ追記します。）

> ネイルホリックはCRシートの形式が案件回によって変わることがあります（基本はGスライド、回によってはスプレッドシート）。修正指示もスライドのコメント（青字）だったりSlackのテキストだったりします。**「今回の正解はどれか」（どのシート・どのコメントが最新か）を最初に確認**してからアップロードしてください。

-----

## これでリーダーのレビューが無くなるわけではありません（大事）

AIチェックは「最初のチェック」です。そのあと、これまで通りリーダーがデザインの中身（余白・トーン・全体の良し悪し）を見て、最終OKを出します。

**AIのOKは「合格」ではありません。**「客観的なミスが見つからなかった」というだけです。最後は必ずリーダーの目を通ります。

-----

## AIがチェックすること

機械的に・客観的に判断できるところを担当します。

1.  **文言** … CRシートの内容と合っているか。抜け漏れ・誤字脱字がないか。
2.  **色番号・色名・素材名** … CRシートで指定された色番号（例：BE300）・色名・使用アイテム名と、クリエイティブ上の表記が一字一句ズレていないか。**ネイルホリックで一番事故が多いポイントなので重点的に見ます。**
3.  **必須要素** … CTAやロゴ、注釈、価格・発売日などがちゃんと入っているか。
4.  **表紙の見切れ** … 1枚目の文字やロゴが、Instagramで端が切れる位置に来ていないか。
5.  **文字の読みやすさ（コントラスト）** … 背景と文字の色が近すぎて読みにくくないか。
6.  **文字サイズ** … 小さすぎて実機で読みづらくないか。
7.  **配色** … ブランドの色から大きく外れていないか。（※ネイルホリックはトンマナ資料が無いため、あくまで参考レベルのチェックです。詳しくは下記「気をつけてほしいこと」を参照）

-----

## AIがチェックしないこと（ここが大事）

余白の感じ、全体のトーン、エモさ、デザインとしての良し悪し――こうした**感覚的・主観的な部分は、これまで通りリーダーが見ます。**

ざっくり言うと、役割分担はこうです。

  - AI … 「読みやすさ」と「間違い探し（特に色番号・色名・素材名）」担当
  - リーダー … 「デザインの質」担当

AIを通したからといって、デザインのクオリティが保証されるわけではありません。AIはあくまで前さばきです。

-----

## 気をつけてほしいこと

### 色番号・色名・素材名は、ぜったいに手打ちしない

ネイルホリックで一番多い事故がこれです。色番号・色名・使用アイテム名は**必ずCRシートからコピペ**してください。手で打ち直すと、どんなに気をつけても「BL920」と「BL921」、「BL096V」と「BL097V」のような一字違いの取り違えが起きます。AIも重点的に見ますが、コピペしておけば、そもそもミスが発生しません。

CRシートでは、同じ色番号が**「文字入れ指示内容」「対象商材」「投稿キャプション（使用色 ▶）」の3か所**に出てきます。この3つがズレていると事故になります。AIはこの3か所の食い違い（例：指示にはあるのにキャプションに入っていない色番号）も見ますが、コピペ元は毎回「文字入れ指示内容」に統一しておくと安全です。

また、色番号には必ず色ライン名がペアで付きます（例：`BL920 Lagoon color`、`WT021F つめ用ファンデ＋`、`YE515 Flower layered color`）。番号だけでなく**ライン名までセットでコピペ**してください。

### 文言も手打ちしない

同じ理由で、文言もCRシートからコピペしてください。

### アート系素材は、ルールに沿って選ぶ

ネイルホリックでアート系の素材を引用するときは、以下のどちらかに限られます。

  1.  **Adobeストック**から、プランナーに選定してもらった指定素材を使う。
  2.  美術関係サイトで**パブリックドメイン**と明記されているもの（商用利用OK）を使う。

たとえば「アートネイル特集」でオーギュスト・ルノワールなどの絵画を使う場合は、パブリックドメイン（商用利用OK）にあたるかを確認したうえで使ってください。AIチェックとは別に、この選定ルールから外れていないかは自分でも必ず確認してください。出典が言えない素材は使わない、が原則です。

### AIは間違えることがあります

「AIがOKと言った＝完璧」ではありません。実際に、AIが見逃してそのまま進んでしまったミスもありました。このフローではみなさん自身がチェックの主役になります。だからこそ、**最終チェックは必ず自分の目で行ってください。** 制作物の責任者はあくまでみなさん自身です。

### ガイドは1枚目だけに付ける

クリエイティブガイドは、各投稿の表紙（1枚目）にのみ付けてレビュー依頼を送ってください。2枚目以降には不要です。

### リーダーへの連絡時は、AIの結果も一緒に渡す

直した内容とAIチェックの結果をセットで渡すと、リーダーが「何をチェック済みで、どこを直したか」を踏まえて確認できます。これがあると、その後のやりとりがスムーズになります。

## よくある質問

**Q. AIがOKを出したら、もうリーダーは見ない？**
いいえ。リーダーのレビューはこれまで通り残ります。AIは前さばきで、デザインの中身と最終OKはリーダーが見ます。

**Q. AIに任せれば、自分の見直しはいらない？**
いいえ。AIは間違えることがあるので、最後は必ず自分の目で確認してください。特に色番号・色名は、コピペしたうえで自分でも見比べてください。

**Q. 色番号が合っているかは、AIが必ず見つけてくれる？**
重点的にチェックしますが、写真の上の細い文字や装飾フォントだと、AIが文字を読み取れず見逃すことがあります。だからこそ「コピペで入れる＋自分の目で確認」が基本です。

**Q. AIが自動で直してくれるの？**
いまは「直すべき点と正しい文言・色番号を教える」ところまでです。反映はみなさんの手で行ってください（編集データやレイアウトを守るためです）。修正の自動化は今後の段階で検討中です。

**Q. 使い方や結果の見方が分からないときは？**
オンボーディング資料を確認のうえ、不明な点はリーダーに気軽に相談してください。
