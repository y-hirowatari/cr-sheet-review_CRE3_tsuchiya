# ネイルホリック CRシート AIレビュー

ネイルホリック案件のクリエイティブレビュー（CRシート）にAIを活用するための、ドキュメント一式です。

レビュー依頼を出す前に、クリエイター自身が専用アプリで制作物をAIにかんたんチェックしてもらい、**素材名・色番号・色名の取り違えなどの客観的なミスを出稿前につぶす**ことをねらいとしています。AIはリーダーのレビューを置き換えるものではなく、リーダーが受け取る提出物をきれいにする「前さばき」です。

各ドキュメントは、実物のCRシート（6月・7月投稿分／IG・X）の構造を確認したうえで具体化しています。

## この案件でのポイント

- **一番の狙いは「取り違えの撲滅」**：ネイル商材が多く、色番号・色名・使用素材の取り違えが過去に多発。複製しないルールで毎回イチから文字を扱うため、構造的に事故が起きやすい。
- **AIには判断させず「照合」させる**：過去、AIに正誤を判断させて自信ありげに見逃したインシデントがあったため、AIの役割は「文字を読み取る」ところまでに限定し、正解（CRシート）との一致は機械が文字単位で比較する。
- **トンマナ資料が無い**：明文化されたデザインレギュレーションが無いため、配色チェックは参考レベルにとどめる（NG判定の根拠にしない）。
- **アート系素材のみルールあり**：Adobeストックのプランナー指定素材、または美術サイトのパブリックドメイン素材（商用OK）に限る。出典の正誤判定はせず、確認の促しにとどめる。
- **CRシート・修正運用がばらつく**：基本はGスライド、回によってはスプレッドシート。修正指示はスライドのコメント（青字）やSlackのテキスト。「今回の正解はどれか」の確定が運用上の肝。

## ステータス

初版のたたき台です。アプリの実装・検証の進捗に合わせて更新していきます。Phase 1 はネイルホリックで、色番号・色名・素材名の照合と文言照合に絞って効果を検証する想定です。
