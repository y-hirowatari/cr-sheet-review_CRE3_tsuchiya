# GAS版：Googleスライドでワンクリック照合（プロトタイプ）

納品がGoogleスライドである点を活かし、**ファイルの受け渡しをせず、スライド上でワンクリック**で
色番号の照合を行う Apps Script です。元ブリーフの「p5-6が指示、p7が貼り付けページ」という構造
（＝1つのCRシートに *指示テキスト* と *提出クリエイティブ画像* が同居）を前提にしています。

- 設計思想：[../docs/AIレビューの仕組み_設計書_チーム共有用.md](../docs/AIレビューの仕組み_設計書_チーム共有用.md)
- 照合ロジック：[../docs/照合ロジック仕様_たたき台.md](../docs/照合ロジック仕様_たたき台.md)
- CLI版（Python）での実証：[../poc/](../poc/)

## 何をするか

1. スライド上の **指示テキスト**（文字データ）から、正解の色番号を取得
2. スライド上の **提出クリエイティブ画像** を **Drive の OCR** で読み取り、色番号を抽出
3. 機械的に照合し、結果を **スライド上のコメント（テキストボックス）** と **スピーカーノート** に出力
   - ❌ 取り違え疑い（正解に無い色番号）／⚠ 未検出（正解にあるが読めず・未反映）／✅ 一致

> AIに正誤を判断させず、OCRは「読む」だけ・一致判定は機械。これがこの仕組みの肝です。

## 導入手順

1. 対象のGoogleスライド（CRシート）を開く → 拡張機能 → **Apps Script**
2. `Code.gs` の内容を貼り付け、エディタの ⚙️（プロジェクトの設定）は既定のままでOK
3. `appsscript.json` を表示（設定で「appsscript.json マニフェスト ファイルをエディタで表示」をON）し、本リポジトリの内容に置き換え
   - これで **Drive 詳細サービス（v2）** と必要な OAuth スコープが有効になります
4. 保存 → スライドを再読み込みすると、メニューに **「AIレビュー」** が出ます
5. 初回実行時に権限承認（Drive/Slides/Documents へのアクセス）を求められます

## 使い方

- **AIレビュー → このスライドを照合**：選択中スライドを照合し、結果を表示＋コメント出力
- **AIレビュー → 全スライドを照合**：画像のある全ページを照合（要確認ページ数を集計）
- **AIレビュー → 直近の結果コメントを消す**：出力したコメントを一括削除

## 設定（`CONFIG`）

| 項目 | 既定 | 説明 |
| :- | :- | :- |
| `truthSource` | `activeThenPrev` | 正解テキストの探し方。アクティブスライドのテキスト→無ければ直前スライド（指示ページ） |
| `ocrLanguage` | `ja` | Drive OCR の言語 |
| `writeComment` | `true` | スライド上にテキストボックスで結果を出す |
| `writeSpeakerNotes` | `true` | スピーカーノートに詳細を出す |
| `codePattern` | `[A-Z]{2}\d{3}[A-Z]?` | 色番号の書式 |

## プロトタイプの制約（実データで詰める前提）

- **スライド構造への依存**：指示テキストと貼り付け画像の対応づけは、いまは「同一スライド／直前スライド」を仮定。
  実際のCRシートの並び（指示ページと貼り付けページの位置関係、1投稿=複数枚）に合わせて `getTruthCodes` を調整します。
  → 実物のスライド構造を1件見せていただければ、そこに合わせ込みます。
- **OCR精度**：装飾フォントや写真上の細い白文字は読み落とし得ます（設計書でいう Phase 1 の重点）。
  Drive OCR で不足する場合は Cloud Vision API へ差し替え可能（精度は上がるが GCP 設定が必要）。
- **確信度**：CLI版(v1)にあるOCRの確信度フィルタは、GAS(Drive OCR)では取得しづらいため、
  当面は「複数画像での検出回数」で代替。誤読対策は運用データを見て強化します。
- **対象は色番号**：まずは事故の多い色番号に集中。色ライン名・素材名・必須文言の照合は次段階。

## 次段階

- 指示↔貼り付けの対応づけを実スライド構造に合わせて確定
- 色ライン名・素材名・必須文言（注釈・CTA）の照合を追加
- 「コメント（青字）」運用に合わせた出力体裁の調整
- スプレッドシート形式CRシート／Slackテキスト指示の正解ソース取り込み
