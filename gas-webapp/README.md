# 社内Webアプリ版：CRシート AIレビュー（スタンドアロンGAS）

CRシート（Googleスライド）上には作り込まず、**レビュー専用の独立Webアプリ**として動かす版です。
納品フロー（レビュー全OK→格納＆貼り付け）はそのまま。**CRシートは読み取り専用**で、コメントや
テキストボックスは一切書き込みません（納品物を汚さない）。

- 設計思想：[../docs/AIレビューの仕組み_設計書_チーム共有用.md](../docs/AIレビューの仕組み_設計書_チーム共有用.md)
- 照合ロジック：[../docs/照合ロジック仕様_たたき台.md](../docs/照合ロジック仕様_たたき台.md)
- スライド内メニュー版（参考・非推奨）：[../gas/](../gas/)

## 何をするか

1. アプリにCRシートのURLを貼って「読み込み」→ 投稿一覧を表示
2. 対象（投稿を選ぶ／ページ番号／全投稿）を選んで「照合する」
3. 指示テキストの色番号（正解）と、貼り付け画像のOCR（提出物）を機械照合
4. 結果を**アプリ画面に**表示：❌取り違え疑い ／ ⚠未検出 ／ ✅一致

> AIに正誤を判断させず、OCRは「読む」だけ・一致判定は機械。これがこの仕組みの肝です。

## 導入手順（スタンドアロン）

1. [script.google.com](https://script.google.com) → **新しいプロジェクト**
2. `Code.gs` の内容を貼り付け
3. **HTMLファイルを追加**：左「ファイル ＋ → HTML」→ 名前 **`Index`** → `Index.html` の内容を貼り付け
4. `appsscript.json` を表示（設定で「appsscript.json マニフェスト ファイルをエディタで表示」をON）し、本フォルダの内容に置き換え
   - **Drive 詳細サービス（v2）** と Webアプリ設定・スコープが入ります
5. 保存

## デプロイ（Webアプリ）

1. 右上 **デプロイ → 新しいデプロイ**
2. 種類 **ウェブアプリ**
3. **次のユーザーとして実行：ウェブアプリにアクセスしているユーザー**（各自の権限でレビュー）
4. **アクセスできるユーザー：(社内ドメイン) 内の全員**
5. デプロイ → 表示された **URL** を社内に共有
6. 各ユーザーは初回アクセス時に権限承認（Slides/Drive/Documents の読み取り等）

> 更新したら **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** で反映。

## 使い方

1. 共有されたアプリURLを開く
2. レビューしたい **CRシートのURL** を貼って「読み込み」
3. 「投稿を選ぶ」等を選び **▶ 照合する**
4. カードで結果を確認（❌/⚠/✅）

## プロトタイプの制約（実データで詰める）

- **OCR精度**：装飾フォント・写真上の細い白文字は読み落とし得る（設計書でいう Phase 1 の重点）。
  Drive OCR で不足する場合は Cloud Vision API へ差し替え可能（精度↑・GCP設定要）。
- **実行時間**：画像が多い投稿・全投稿はOCR回数が多く時間がかかる（google.script.run の上限に注意）。
  まずは投稿単位・ページ指定での利用を推奨。
- **対象は色番号**：色ライン名・素材名・必須文言（注釈/価格/発売日）の照合は次段階。

## 次段階（この方針での発展）

- **「先祖還り」対策**：貼り付けクリエイティブと、Driveの**格納ファイル**が一致しているかの照合
  （格納先フォルダ/命名規則が決まれば、貼り付け画像 ↔ 格納物 の突き合わせを追加可能）
- 色名・素材名・必須文言の照合、コントラスト・見切れ等の画像チェック
- 上流の指示書（発注書）との突き合わせ（正解ソースの拡張）
