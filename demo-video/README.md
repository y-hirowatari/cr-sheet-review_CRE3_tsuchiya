# DAOX プロダクト紹介動画

デモサイト( https://daox-zeta.vercel.app )を Playwright で実際に操作しながら録画したプロダクトツアー動画(1280x720, H.264)。

## `daox_demo_52s.mp4` — 機能ツアー版(約52秒・推奨)

テンポよく13の機能をカット割りで紹介。各シーンに機能名+説明のキャプション、画面種別バッジ(ユーザー画面/管理者画面)付き。

| セクション | 内容 |
|---|---|
| タイトル | DAOX — 地域コミュニティDAOプラットフォーム |
| 01 ユーザー画面 | ホーム&掲示板 → 投票(選択→投票の実操作) → QRチェックイン → タスク受発注(詳細表示) → ウォレット → DM&トークン送付 → メンバー |
| 02 管理者画面 | ダッシュボード → モデレーション → メンバー管理 → 店舗QR発行 → 投票管理 → トークン経済 → ランク設計 |
| エンド | キャッチコピー+機能チップ+デモURL |

## `daox_demo_30s.mp4` — ショート版(30秒)

主要機能のみのダイジェスト(ホーム/チェックイン/タスク/ウォレット/ダッシュボード/モデレーション/トークン)。

## 再生成方法

```sh
node record60.mjs   # 52秒版のセグメント録画(要 playwright + chromium)
node record.mjs     # 30秒版
# その後 ffmpeg で各セグメントを trim → concat → H.264 エンコード
```

`fetchproxy.mjs` は録画環境のegressプロキシ経由で通信するためのリクエストインターセプタ(通常環境では不要)。
