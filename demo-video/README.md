# DAOX プロダクト紹介動画(30秒)

`daox_demo_30s.mp4` — デモサイトを実際に操作しながら録画した30秒のプロダクトツアー動画(1280x720, H.264)。

## 構成
1. タイトルカード「DAOX — 地域コミュニティDAOプラットフォーム」
2. ユーザー画面ツアー: ホーム(お知らせ・掲示板・投票タブ) → QRチェックイン → タスク(詳細表示) → ウォレット
3. 転換カード「管理者画面」
4. 管理者画面ツアー: ダッシュボード → 掲示板モデレーション → トークン・ランク管理
5. エンドカード(デモURL)

## 再生成方法
Playwright でデモサイト( https://daox-zeta.vercel.app )を自動操作しつつ画面録画し、ffmpeg でセグメントを結合・30秒に正規化しています。

```sh
node record.mjs   # 要: playwright + chromium, セグメントwebmとmeta.jsonを生成
# その後 ffmpeg で各セグメントを trim → concat → setpts で30秒に正規化 → H.264エンコード
```

`fetchproxy.mjs` は録画環境のegressプロキシ経由で通信するためのリクエストインターセプタ(通常環境では不要)。
